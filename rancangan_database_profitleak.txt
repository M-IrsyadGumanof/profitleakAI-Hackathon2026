========================================================================
 RANCANGAN DATABASE - PROFITLEAK AI
 (Pendamping gambar: rancangan_database_profitleak.png)
 Sumber data : Olist E-Commerce (orders, order_items, products, sellers,
               customers) + hasil model profitleak_final_model_v5.pkl
========================================================================

TUJUAN
  Menyimpan data transaksi pengiriman serta hasil prediksi tarif ongkir dan
  penandaan kebocoran profit (profit leak) dari model v5.

DAFTAR TABEL
  1. customers     - data pelanggan (lokasi)
  2. sellers       - data penjual (lokasi)
  3. products      - data produk (dimensi & berat)
  4. orders        - header pesanan
  5. order_items   - baris item pesanan + FITUR MODEL (weight_kg,
                     volume_cm3, distance_km) + tarif aktual (freight_value)
  6. predictions   - hasil prediksi tarif dari model v5
  7. leak_flags    - hasil deteksi kebocoran (rasio vs threshold)

RELASI
  customers   1 --- N  orders         (orders.customer_id -> customers)
  orders      1 --- N  order_items    (order_items.order_id -> orders)
  products    1 --- N  order_items    (order_items.product_id -> products)
  sellers     1 --- N  order_items    (order_items.seller_id -> sellers)
  order_items 1 --- N  predictions    (predictions.order_item_id)
  predictions 1 --- 1  leak_flags     (leak_flags.prediction_id)

FITUR MODEL v5 (dipakai dari order_items)
  - weight_kg    = product_weight_g / 1000
  - volume_cm3   = length_cm * height_cm * width_cm
  - distance_km  = haversine(lokasi seller, lokasi customer)
  - price_log    = log(price)         -> dihitung di backend/predictions
  Threshold deteksi leak = 1.102309 (rasio actual/predicted)

ALUR DATA
  orders + order_items (+ products, sellers, customers)
     -> hitung fitur (weight_kg, volume_cm3, distance_km)
     -> model v5 -> predictions
     -> leak_flags (is_leak)


========================================================================
 DDL (PostgreSQL) - bisa langsung dijalankan
========================================================================

CREATE TABLE customers (
    customer_id      CHAR(32)       PRIMARY KEY,
    zip_code_prefix  VARCHAR(5),
    city             VARCHAR(64),
    state            CHAR(2),
    lat              DECIMAL(9,6),
    lng              DECIMAL(9,6)
);

CREATE TABLE sellers (
    seller_id        CHAR(32)       PRIMARY KEY,
    zip_code_prefix  VARCHAR(5),
    city             VARCHAR(64),
    state            CHAR(2),
    lat              DECIMAL(9,6),
    lng              DECIMAL(9,6)
);

CREATE TABLE products (
    product_id       CHAR(32)       PRIMARY KEY,
    category         VARCHAR(80),
    weight_g         INT,
    length_cm        INT,
    height_cm        INT,
    width_cm         INT
);

CREATE TABLE orders (
    order_id         CHAR(32)       PRIMARY KEY,
    customer_id      CHAR(32)       REFERENCES customers(customer_id),
    order_status     VARCHAR(20),
    purchase_ts      TIMESTAMP,
    delivered_ts     TIMESTAMP
);

CREATE TABLE order_items (
    order_item_id    BIGSERIAL      PRIMARY KEY,
    order_id         CHAR(32)       REFERENCES orders(order_id),
    product_id       CHAR(32)       REFERENCES products(product_id),
    seller_id        CHAR(32)       REFERENCES sellers(seller_id),
    price            DECIMAL(10,2),
    freight_value    DECIMAL(10,2),   -- tarif ongkir AKTUAL
    weight_kg        DECIMAL(6,3),    -- fitur model
    volume_cm3       DECIMAL(12,2),   -- fitur model
    distance_km      DECIMAL(10,4)    -- fitur model
);

CREATE TABLE predictions (
    prediction_id    BIGSERIAL      PRIMARY KEY,
    order_item_id    BIGINT         REFERENCES order_items(order_item_id),
    predicted_rate   DECIMAL(10,2),
    price_log        DECIMAL(8,4),
    model_version    VARCHAR(10)    DEFAULT 'v5',
    created_at       TIMESTAMP      DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE leak_flags (
    flag_id          BIGSERIAL      PRIMARY KEY,
    prediction_id    BIGINT         REFERENCES predictions(prediction_id),
    actual_rate      DECIMAL(10,2),
    ratio            DECIMAL(8,4),
    threshold        DECIMAL(8,4)   DEFAULT 1.102309,
    is_leak          BOOLEAN,
    created_at       TIMESTAMP      DEFAULT CURRENT_TIMESTAMP
);

-- Index untuk percepat join & filter
CREATE INDEX idx_orders_customer        ON orders(customer_id);
CREATE INDEX idx_items_order            ON order_items(order_id);
CREATE INDEX idx_items_product          ON order_items(product_id);
CREATE INDEX idx_items_seller           ON order_items(seller_id);
CREATE INDEX idx_predictions_item       ON predictions(order_item_id);
CREATE INDEX idx_leak_prediction        ON leak_flags(prediction_id);
CREATE INDEX idx_leak_is_leak           ON leak_flags(is_leak);

========================================================================
 CATATAN
  - Tiap prediksi menghasilkan tepat 1 leak_flags (relasi 1:1).
  - model_version disimpan agar hasil lama tetap dapat dilacak.
  - Nilai valid input model (dari info JSON):
      weight_kg   : 0.05 - 30.0
      distance_km : 1.4896 - 3135.7885
      volume_cm3  : 352.0 - 244608.0
      price       : 4.99 - 2110.0
  - Currency: BRL (Real Brasil) sesuai dataset Olist.
